# `mogo`

These are opinionated set of helpers and wrappers for building Go systems. It
contains common utilities and patterns we have encountered while working on
different Go systems at [Momoli](https://momoli.dev).

Checkout [full app example](./example/full/main.go). It showcases bootstrapping
a Go application using all the `mogo` toolkit. Other individual
[examples](./example) show each package in detail.
