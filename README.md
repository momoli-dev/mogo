# `mogo`

These are opinionated set of helpers and wrappers for building Go systems. It
contains common utilities and patterns we have encountered while working on
different Go systems at [Momoli](https://momoli.dev).

Check out the [full app example](./example/full/main.go) for bootstrapping a Go
application with the application context, HTTP, API, PostgreSQL, and Redis
helpers. The other [examples](./example) include runnable applications and tests
for several packages.
